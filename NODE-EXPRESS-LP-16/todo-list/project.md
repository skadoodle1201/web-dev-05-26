# Todo Listing Application

## Requirement

1. Create a todo -> 1 post api to create todo
2. Update/Edit Todo -> 1 put/patch to update todo
3. Read Todo list -> 1 get to fetch todo list
4. Mark Done to a todo -> 1 put/patch to update todo status
5. Delete todo -> 1 delete to delete todo

A todo will contain

```
{
    "task" : <string>,
    "status" : <boolean>
}
```
