# Todo Listing Application

## Requirement

1. Read Todo list -> 1 get to fetch todo list -> DONE
2. Create a todo -> 1 post api to create todo -> Done
3. Update/Edit Todo -> 1 put/patch to update todo -> Done
4. Mark Done to a todo -> 1 put/patch to update todo status -> Done

5. Delete todo -> 1 delete to delete todo

A todo will contain

```
[{
    "task" : <string>,
    "status" : <boolean>
}]
```
